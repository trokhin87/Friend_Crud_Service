# Friend Service (Сервис друзей)

## 1. Назначение сервиса
**Friend Service** управляет списком друзей пользователей. Он позволяет добавлять, удалять и обновлять друзей, а также управлять поздравлениями и пожеланиями.

### Основные функции:
- Добавление/удаление друзей.
- Обновление информации о друзьях.
- Объединение данных о пожеланиях и интересах друзей.

---

## 2. Архитектура и зависимости

### **Технологии и фреймворки:**
- **ASP.NET Core** – основной фреймворк для API.
- **Serilog** – логирование.
- **Swagger** – документирование API.
- **PostgreSQL** – база данных для хранения списка друзей.

### **Взаимодействие с другими микросервисами:**
- **DBProxy** – передача данных о друзьях и пожеланиях.

### **Используемые внешние сервисы:**
- PostgreSQL (база данных)

---

## 3. Способы запуска сервиса

### **Запуск с Docker**
```sh
docker-compose up --build
```

### **Запуск без Docker**
```sh
dotnet run
```

### **Переменные окружения (.env):**
```env
DB_CONNECTION_STRING=your_database_connection_string
```

---

## 4. API документация
Swagger UI доступен по адресу:
```
http://localhost:5001/swagger
```

### **Основные эндпоинты:**
| Метод | URL | Описание |
|--------|-------------------------|--------------------------------|
| POST | /api/friend/add | Добавление друга |
| DELETE | /api/friend/delete | Удаление друга |
| PUT | /api/friend/update | Обновление информации о друге |
| GET | /api/friend/list/{appId} | Получение списка друзей |
| POST | /api/friend/addWithWish | Добавление друга с пожеланиями |
